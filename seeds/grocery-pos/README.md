# Grocery POS Lite (template)

Kasir + inventori sederhana untuk warung/toko kelontong. Jalan dengan `docker compose up`.

- Tambah produk ke keranjang, bayar, cetak struk (print browser).
- Penjualan harian tersimpan di browser (localStorage per hari).
- Cari produk, ubah daftar produk di `index.html` (array `products`).

**Kustomisasi via Slaver Team:** buka project ini → buat issue ("Tambah QRIS", "Laporan mingguan") → Start agent run → review → deploy ke VPS.
