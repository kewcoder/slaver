# F&B Ordering Lite (template)

Pemesanan meja + tiket dapur untuk warung/cafe. Jalan dengan `docker compose up`.

- Tab Menu: pilih item, kirim ke dapur per nomor meja.
- Tab Dapur: antrian real-time (localStorage), tandai selesai.
- Edit `MENU` di `index.html` untuk ganti menu & harga.

**Kustomisasi via Slaver Team:** buat issue ("Tambah pembayaran QRIS", "Struk dapur") → Start agent run → review → deploy ke VPS.
